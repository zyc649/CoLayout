# CoLayout artwork

colayout-e2.png is the approved transparent master artwork. colayout-e2.ico contains Windows icon sizes generated by tools/build_app_icon.py. The CoLayout artwork is distributed under the repository MIT license.

Keep transparent edge pixels free of an opaque background. Verify small sizes on light/dark taskbars and the application's dark UI. app_identity.py and the optional shortcut use these same resources. Do not modify the shared Python executable or system file associations.
