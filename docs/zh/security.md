# 安全与数据边界

[项目首页](../../README.zh-CN.md) · [文档目录](index.md) · **简体中文** | [English](../en/security.md)

CoLayout 是可信本机桌面工具。HTTP token 用来验证本机客户端，不是加固的多租户服务。保持服务绑定回环地址，不通过公网代理暴露，也不分享 agent-connection.json。

版图 Agent 只获得自己的客户端目录权限。维护／工艺配置 Agent 的源码、Bridge、SSH 权限由宿主分别控制；生成的 AGENTS.md 不是操作系统沙箱。

.env、Bridge 状态、SSH 密钥、工作区、报告、工艺配置包和原生事务日志应保密。工艺导出不含凭据或原始规则文件，但仍可能包含敏感工艺参数和服务器路径，分享前需要审核。

不要把秘密贴进 issue。发现安全漏洞时，优先使用已启用的 GitHub 私密漏洞报告；若不可用，只开一个请求私密渠道的简短 issue，不附利用细节或敏感资料。

同步失败或超时不授权删除日志或强制写入。保留回执，对未知原生结果进行对账。来自不可信来源的配置或文件，在启用前应先核验。

本仓库不提供公共 EDA 服务器、托管模型服务或 foundry 工艺库。
