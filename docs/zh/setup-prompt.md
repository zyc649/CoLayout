# 可复制的初始化提示词

**简体中文** | [English](../en/setup-prompt.md) · [项目首页](../../README.zh-CN.md) · [文档目录](index.md)

把下面的占位符替换为自己的信息后交给初始化 Agent。服务器 IP 不包含远程用户名；即使已配置免密，也建议明确填写用户名。不要提供密码、私钥或 token。工程目录、PID 不清楚时可以先只读查找，仍不明确再询问。

~~~text
请将 https://github.com/zyc649/CoLayout 克隆到我指定的本地目录，把实际仓库根目录作为本对话的工作区。

这个对话同时负责初始化和后续源码开发、bug 修复与重构。请先读仓库 AGENTS.md、源码接手指南、软件架构和源码实现详解；不要依赖旧对话或私有交接文件。版图绘制会在另一个只授权客户端目录的对话进行。

请按照仓库文档依次完成：
1. 安装固定版本依赖，核对项目级 colayout-pdk、colayout-layout-agent 和上游 virtuoso 技能。宿主尚未发现技能时直接读取 SKILL.md，不复制到全局。
2. 核实 SSH 和目标 Virtuoso。已有匹配的 Bridge 环境则复用；不要重启或杀掉 Virtuoso。多窗口或目标不明确时请我选择。
3. 启动 Windows APP，验证 API 就绪。
4. 使用 colayout-pdk 读取我已保存并打开的 Layout 样例，核对实际样例内容、技术资料和规则文件，完成副本验证并提交工艺提案待我审核。不要代替我批准，也不要修改原样例或共享 PDK。
5. 使用 colayout-layout-agent 建立独立客户端目录，验证连接、工具发现和存档路径。工艺待审核不妨碍先准备客户端；实际画图需启用工艺后进行。
6. 如果发现部署或代码问题，定位后修复并完成相应测试。最后报告源码目录/版本、连接目标、提案状态、客户端目录、测试结果和未完成项。

本地目标目录：<目录>
服务器 IP 或 SSH 别名：<主机>
SSH 用户名：<用户名>
SSH 状态：已完成免密登录
工艺名称：<名称>
目标工程目录／Virtuoso PID：<已知则填写；否则先只读确认>

Layout 样例已保存并在目标 Virtuoso 打开，包含 NMOS、PMOS、电阻、MIM 电容、各相邻金属层的默认 1×1 标准孔（含顶层），以及所需 P/N 类型的原生 90° 开放 MPP（直段、拐角、两个端头）。闭环作为补充参考。没有真实双排样例，不配置双排。
请核对实际 master/CDF 与清单是否一致。缺少样例、规则或必要信息时明确告知我，不编造配置；独立可继续的步骤先完成。
~~~

执行细节见 [Agent 初始化执行手册](agent-setup.md)。这份提示词不要求 Agent 一次性声称所有 PDK 或所有 bug 已验证；交付结果应说明实际完成范围。
