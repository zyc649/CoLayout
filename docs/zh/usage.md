# 软件使用说明

**简体中文** | [English](../en/usage.md) · [项目首页](../../README.zh-CN.md) · [文档目录](index.md)

## 工作区

APP 只维护一份权威本地文档。人和 API 客户端共享对象、操作区、UID 和撤销语义。本地操作区是组织工作的方法，不会在 Virtuoso 中创建新的子 cell。

工艺审核后，从“文件”菜单显式导入目标 Layout 及其对应的原理图参考。真实物理目标来自 Layout 的 PIN／网络；原理图辅助理解电路、匹配与设计意图。它不替代实际几何连接。

框出需要工作的器件建立操作区，检查接口，把操作区 ID 交给版图 Agent。暂时没有实体接入的接口可以作为待补义务保留，后续保护环或连线仍必须真正接通；虚拟 PIN 标记不会凭空产生金属。

## 一个基本协作流程

1. 人选择源版图并划分本地操作区。
2. 每个版图 Agent 接入用户分配的区域。兄弟区可并行；父区只管理直接子区外框和接口。
3. 按需要先用方位 PIN 模式完成内部主体，补齐器件接入、布线和已配置的保护环。
4. 使用属性面板／API 收紧操作区，切换固定 PIN，完成到边缘接口的真实引出。
5. 高频运行本地检查并查看提醒，在合适阶段运行服务器 DRC；当前全区两项证据均通过后才能完成验收。
6. 人显式将核对后的工作区写入 Virtuoso，再完成必要的全芯片检查、LVS 和最终签核。

Agent 占用时，该操作层的人类物理编辑会锁定，查看和导航仍可用；定位框是有限的实时指导例外。不要通过结束其他客户端会话来绕过锁定。

## 层次与局部布线豁免

普通叶 PCell 参与本地／服务器检查，真正的原生层次对象保持黑盒。如果公开 PIN 位于黑盒内部，可以为该对象的指定金属层设置局部布线通道。它不开放内部编辑，也不豁免其他对象或独立禁布区。

APP 子操作区与原生层次是两套结构。子区内部由其自身 Agent 负责；父层移动子区外框时，内容整体变换，并按依赖关系使相应旧结果失效。

## 检查结果分别代表什么

工艺库的“绘图与图层”页可勾选“允许 Agent 使用算法自动布线”，默认关闭（含旧配置）。只有人保存/审核后才向 Agent 开放 route_region；人类 UI 自动布线不受影响，排列、对齐、自动过孔等其他 Agent 工具也不受影响。

“收紧操作区”按内容及直接子区 PIN 外形保留适量通道：各方向取最大 PIN 尺寸的一半，再加约 10%（至少一个制造网格）。UI 与 API 一致，保留 PIN 模式和原生几何，只在原框内收紧；原框过紧时不额外提示。

- 本地连通检查针对公开目标和已支持材质，不抽取完整器件内部电路。
- 本地 DRC 包含已配置的简单几何规则、设计提醒、跨器件 Poly 冲突、已配置 MIM 区域过孔防护和内部金属误接提醒。不支持的宽度几何直接跳过。
- 内部金属接触是非阻断 warning；真实物理错误，以及不完整、过期、截断的检查仍阻断完成。
- 服务器 DRC 使用包含当前本地修改的原生私有副本，按人批准的工艺报告策略审阅，同时保留原始结果。
- 两项区域检查通过，不等于全芯片 DRC 或 LVS 签核。

不要为了消除结果而改器件参数或自行增加豁免。同步遇到基线不符时，先核对服务器源或依赖实际变化，再执行恢复／同步。

审核本地规则时，source/note 只是依据和说明，不会自动实现区域例外或电气条件。有用的简化检查通常应保持启用，允许因遗漏条件造成有限误报，并审核备注中的简化范围及可能漏检。只有依据不足、算法无法执行，或频繁误报合法基础结构以至于影响使用时，才禁用。备注不代表遗漏条件已经实现，完整服务器 DRC 仍然需要执行。

本地 `spacing` 不区分同网/异网，也不比较网络名称；规则 ID 不会选择原始 deck 的条件。同层启用多条间距规则时全部执行，检查覆盖范围内须满足最大启用阈值，并非按条件选择阈值。配置者须根据当前 PDK 选择有依据的简化检查，明确实际行为、原始依据及未覆盖项；配置检查通过不代表已实现原始条件。版图 Agent 不能根据规则名称或备注推断额外能力，也不能自行修改工艺配置绕过检查。

## 保存、加载和恢复

APP 自动维护内部工作副本和恢复记录；“保存／另存为”才更新用户指定的便携 JSON 存档。之后继续编辑不会不断改写该存档。

Agent 的 workspace save 生成独立快照；load 与人端打开存档的语义一致，先备份，再替换整个当前工作区。它要求会话和任务空闲、没有未决原生事务，也不会自动同步 Virtuoso。

请求超时不代表未执行。保留原 request_id、body 和 pending，查询或重试同一个请求；不要换 ID 再创建一次。原生写入不确定时保留回执，走核对恢复流程，不清记录绕过失败。

## 常用默认快捷键

| 按键 | 功能 |
|---|---|
| F | 适合窗口 |
| Ctrl+E | 返回上层 |
| Ctrl+R | 旋转所选支持对象 90° |
| Ctrl+Z 或 U | 撤销 |
| Ctrl+Y 或 Ctrl+Shift+Z | 重做 |
| Ctrl＋滚轮 | 切换层次透视程度 |
| Esc | 取消当前交互 |

快捷键可在人端设置，输入框内仍保留文字编辑行为。面板按钮用于开关对应面板；自动布线入口位于“视图”菜单。
